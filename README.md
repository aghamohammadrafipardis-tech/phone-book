# 📞 Phone Book

A simple and interactive command-line (CLI) application written in Python for managing contacts and phone numbers.

## ✨ Features

- ➕ Add a new contact
- 📱 Add a phone number to an existing contact (supports multiple numbers per contact)
- 🔍 Search for a phone number by contact name
- 🗑️ Delete a contact
- 🔢 Show the total number of contacts
- ❌ Exit the program

## 🚀 How to Run

To run the program, simply make sure Python 3 is installed on your system. Then run the following command in your terminal:

```bash
python phonebook.py
