
# 📞 Phone Book 

A Python-based application designed to manage personal contacts and make storing, searching, and organizing contact information easier.

## 🎯 Problem

Managing contact information manually can become inconvenient, especially when the number of contacts increases. Finding, updating, or deleting contact details can also take time.

This project provides a simple digital solution for storing and managing contacts efficiently.

## ✨ Features

- **Add Contacts:** Store new contacts with their personal information.
- **View Contacts:** Display saved contacts.
- **Update Contacts:** Modify existing contact information.
- **Delete Contacts:** Remove unwanted contacts.
- **Search Functionality:** Find contacts using names or other available fields.
- **Data Storage:** Save contact information for future access.
- **User-Friendly Interaction:** Navigate through the application using a simple menu.
